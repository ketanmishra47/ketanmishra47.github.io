P—004 AI Workflows Shipped 2024

Claude creative replication pipeline.

An on-demand agentic workflow that analyzes winning creatives and generates replicas. Claude + Gemini, driven by a system-instructions playbook.

Built forAdsparkx creative team
FormatAgentic workflow · VS Code
StatusPhase 1 active · Phase 2 in dev

// Context

Manual creative analysis had two problems. Subjectivity: every analyst named the same script's patterns differently, so the dataset of "what works" was noisy. Human error: missed details meant the next variant rebuilt the wrong elements.

The bet: a repo of everything that works, analyzed the same way every time. Scripts and angles into structured pattern data. Visual frames into structured pattern data. Both feeding a library the team writes the next variant from.

// Approach

Built as an on-demand agentic workflow in VS Code. Claude runs the script-side analysis. Gemini reads the video frames for visual pattern data. Both agents work off a system-instructions file that defines the analysis schema, ensuring every script gets parsed against the same structure.

The schema covers psychological triggers and first-impact analysis. Every script breaks down into 6 structural elements: pure claim, pure proof, bonding and relationship building, setup for later payoff, objection handling, storytelling. The taxonomy stays consistent across the library.

Phase 1 takes existing winning creatives and produces analysis tables (file, niche, hook type, archetype, distinctive element), hook taxonomies ranked by frequency, structural breakdowns by timing, compliance flags on every script line, and full replica scripts ready to shoot. Each output is structured so the next variant has the working pattern baked in.

Phase 2 (in development) extends the pipeline into video generation. Full talking-head sequences with B-rolls and avatar variations, fed in manually as seeds. Currently a separate workflow being shaped.

// Outcome

The pattern library exists. Every winning script in the analyzed batch sits in structured form. Hooks taxonomized. Structural elements named. Compliance flags surfaced. Replica scripts ready to shoot.

The next variant gets written against the library. A person's memory of last week's winners stopped being the source of truth. Two analysts running the pipeline get the same output.

Pattern analysis stopped being a person. It became a pipeline.
