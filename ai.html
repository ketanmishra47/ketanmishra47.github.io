Claude pipelines.

Claude is the LLM I default to for creative analysis and structured generation. The work runs in pipelines, not chat sessions.

I've built Claude workflows that analyze winning creatives and turn the patterns into replica scripts and video generation prompts. Other pipelines handle competitor analysis and angle generation. SOP assistance runs as its own pipeline for the team.

The discipline: every Claude pipeline has a structured input and a structured output. Chat is for exploration. Pipelines do the production work.

n8n workflows.

n8n is the automation glue. It connects ClickUp, Slack, Notion, Google Sheets, and AI APIs into workflows that run without humans in the loop.

I've built n8n workflows that route briefs automatically, trigger reviews when assets ship, sync performance data back to tickets, and push daily intel digests to the team. The platform handles thousands of events without anyone touching it.

n8n is the layer between human creative work and the systems around it.

KIE & Seedance.

AI video generation tools. KIE for image-to-video and rapid concept testing. Seedance for full AI-gen creative production.

I've built workflows where Claude analyzes winning patterns and generates structured prompts for these tools. The output: AI-gen creatives that match what's actually winning in production.

The discipline: tool output is bounded by input quality. Structured prompts beat creative-sounding prompts every time.

ClickUp automations.

ClickUp is the operations layer for creative work. Briefs live there. Reviews trigger there. Performance gets logged there.

I've built ClickUp setups that handle creative ops end-to-end. Status fields auto-update. Performance tags pull from external data. Briefs route to the right human based on type and vertical.

When ClickUp runs the operational layer, the team focuses on what only humans can do.

Research cycles compressed from days to hours. The team stopped doing manual scraping.
